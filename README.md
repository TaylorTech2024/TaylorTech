## Estrutura
- `docs/` → site publicado no GitHub Pages
  - `index.html` → home/portfólio
  - `planos/` → loja (links Kiwify)
  - `briefing/` → formulário de briefing
  - `css/` e `js/` → estilos e scripts

## Deploy (GitHub Pages)
1. Repositório → Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main`
4. Folder: `/docs`
5. Save
